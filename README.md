# Prompt — Extração de Séries Temporais BACEN

Prompt operacional de pesquisa acadêmica, mantido por [Darci de Borba](https://www.darcideborba.com.br), pesquisador no Instituto de Pesquisa Econômica Aplicada (Ipea). Parte da coleção de prompts que uso para conduzir, com apoio de IA, etapas recorrentes de pesquisa em administração pública, transformação digital e temas correlatos.

## Conteúdo

- `PROMPT.md` — o prompt completo, com papel esperado da IA, regras invioláveis, passo a passo, critérios de aceite e armadilhas conhecidas.
- `bacen_extraido.R` — código extraído do prompt (ver nota abaixo).

## Script

`bacen_extraido.R` contém o código extraído do próprio prompt (trechos R/Python citados no documento), servindo de ponto de partida — precisa de adaptação ao projeto e aos dados reais.
